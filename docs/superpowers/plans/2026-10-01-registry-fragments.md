# Service Registry Fragments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate `~/.sandbox/services.yaml` from a `.sandbox/services.yaml` fragment committed in each app repo, so a new developer gets a complete registry from `sandbox setup` alone.

**Architecture:** A new pure module `packages/sandbox-core/registry_sync.ts` discovers fragments under `paths.repos_root`, merges them over sandbox-owned defaults and under a per-machine `services.local.yaml`, and writes the generated registry. `sandbox setup` runs it as a step after the repo clones; `sandbox registry sync` runs it alone. Nothing that *reads* the registry changes.

**Tech Stack:** TypeScript (ESM, `tsc` to `dist/`), `yaml` 2.x (`parse`/`stringify`), `node:test` for sandbox-core (`*.test.mjs` against `dist/`), vitest for the CLI, commander for CLI wiring.

**Spec:** `docs/superpowers/specs/2026-10-01-registry-fragments-design.md`

## Global Constraints

- Fragment location is exactly `<repo>/.sandbox/services.yaml`; allowed top-level keys are `services`, `setup_services`, `infrastructure`, plus ignored `x-*` keys.
- Placeholders are exactly `{{home}}`, `{{repos_root}}`, `{{workspaces_root}}`; every other `{{...}}` and all `${...}` text passes through untouched (the registry carries `${CONTEXT7_API_KEY:-}` and `${SANDBOX_MCP_TOKEN}` that must survive, and `generate.ts` resolves single-brace `{service}` refs later).
- Generated file header starts with the exact line `# GENERATED by \`sandbox registry sync\` — do not edit.`; a pre-existing file without it is backed up to `services.yaml.bak-<unix-seconds>` before the first overwrite.
- Output key order: `archetypes`, `mcp_servers`, `k8s_context`, `services`, `infrastructure`, `setup_services`, `repos`; any other top-level key from the local overlay follows.
- Collisions that fail the merge, naming both owners: duplicate service, setup service or infrastructure name; duplicate `port_offset` across services; duplicate `k8s_forward_port` across services and infrastructure.
- `~/.sandbox/services.local.yaml` is seeded once by setup via `seedFile` and never overwritten.
- Setup-step labels follow the existing `config <file>` / `repo <name>` convention; failures are `Step` objects, never thrown.
- Changesets name `@jbbz-sandbox/sandbox-cli`, never `sandbox-core`.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

- A fragment with a YAML syntax error must fail the step naming the file, not crash setup. Pinned in Task 1 (`discoverFragments` parse error test).
- A fragment whose `services:` is a list or scalar instead of a map must fail naming the file and section. Pinned in Task 1.
- A `path: .` service must not produce a `path_mappings` entry (an empty-string key would match every file in `detect`). Pinned in Task 1.
- `services.local.yaml` that parses to `null` (empty file) must behave as `{}`. Pinned in Task 2.
- `repos_root` that does not exist yet (fresh machine, `--check`) must report "no fragments", not throw ENOENT. Pinned in Task 2.

Create `packages/sandbox-core/registry_sync.ts`:

```ts
/**
 * Service-registry generation from per-repo fragments.
 *
 * Each app repo commits `<repo>/.sandbox/services.yaml` — a slice of the
 * registry schema holding only `services:`, `setup_services:` and
 * `infrastructure:`. This module scans `paths.repos_root` for those
 * fragments, merges them over the sandbox-owned defaults (archetypes, MCP
 * servers) and under the per-machine `~/.sandbox/services.local.yaml`, and
 * writes `~/.sandbox/services.yaml`. Nothing that READS the registry knows
 * any of this happened: readers keep loading the one generated file.
 *
 * Philosophy matches machine_setup.ts: `syncRegistry` reports through Step
 * objects and never throws; the pure functions throw RegistryError with a
 * message that names the file and key, and syncRegistry turns that into a
 * failing step.
 */

import * as fs from "node:fs";
import * as os from "node:os";
import * as path from "node:path";

import { parse as parseYaml, stringify as stringifyYaml } from "yaml";

import { getReposRoot, servicesLocalYamlPath, servicesYamlPath, workspacesRoot } from "./config.js";
import type { Step } from "./machine_setup.js";
import { REGISTRY_DEFAULTS } from "./scaffold.js";

/** Where a repo's fragment lives, relative to its checkout root. */
export const FRAGMENT_REL = path.join(".sandbox", "services.yaml");

/** First line of every generated registry; its absence marks a hand-written file. */
export const GENERATED_MARKER = "# GENERATED by `sandbox registry sync` — do not edit.";

const FRAGMENT_KEYS = ["services", "setup_services", "infrastructure"] as const;
type FragmentKey = (typeof FRAGMENT_KEYS)[number];

/** Top-level order of the generated document; local-only keys follow. */
const OUTPUT_ORDER = [
  "archetypes", "mcp_servers", "k8s_context", "services", "infrastructure", "setup_services", "repos",
];

export class RegistryError extends Error {}

export interface Fragment {
  /** Directory name under repos_root — the service's `repo:`. */
  repo: string;
  /** Absolute path of the fragment file, for messages. */
  path: string;
  doc: Record<string, any>;
}

export interface PlaceholderPaths {
  home: string;
  repos_root: string;
  workspaces_root: string;
}

function isDict(value: unknown): value is Record<string, any> {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}

/** Every `<dir>/.sandbox/services.yaml` directly under *reposRoot*, sorted by dir name. */
export function discoverFragments(reposRoot: string): Fragment[] {
  if (!fs.existsSync(reposRoot)) return [];
  const out: Fragment[] = [];
  for (const repo of fs.readdirSync(reposRoot).sort()) {
    const file = path.join(reposRoot, repo, FRAGMENT_REL);
    if (!fs.existsSync(file)) continue;
    let doc: unknown;
    try {
      doc = parseYaml(fs.readFileSync(file, "utf8"));
    } catch (e) {
      throw new RegistryError(`${file}: ${e instanceof Error ? e.message : String(e)}`);
    }
    out.push({ repo, path: file, doc: isDict(doc) ? doc : {} });
  }
  return out;
}

const PLACEHOLDER = /\{\{\s*(home|repos_root|workspaces_root)\s*\}\}/g;

/** Expand `{{home}}`, `{{repos_root}}`, `{{workspaces_root}}` in every string, at any depth. */
export function expandPlaceholders<T>(value: T, paths: PlaceholderPaths): T {
  if (typeof value === "string") {
    return value.replace(PLACEHOLDER, (_m, key: keyof PlaceholderPaths) => paths[key]) as T;
  }
  if (Array.isArray(value)) {
    return value.map((v) => expandPlaceholders(v, paths)) as T;
  }
  if (isDict(value)) {
    const out: Record<string, any> = {};
    for (const [k, v] of Object.entries(value)) out[k] = expandPlaceholders(v, paths);
    return out as T;
  }
  return value;
}

/** Maps merge recursively; scalars and lists from *over* replace. */
function deepMerge(base: Record<string, any>, over: Record<string, any>): Record<string, any> {
  const out: Record<string, any> = { ...base };
  for (const [k, v] of Object.entries(over)) {
    out[k] = isDict(v) && isDict(out[k]) ? deepMerge(out[k], v) : v;
  }
  return out;
}

/** Record *who* owns *key*; a different prior owner is a collision. */
function claim(owners: Map<string, string>, key: string, who: string, label: string): void {
  const prior = owners.get(key);
  if (prior !== undefined && prior !== who) {
    throw new RegistryError(`${label} is defined by both ${prior} and ${who}`);
  }
  owners.set(key, who);
}

export interface MergeOptions {
  defaults: Record<string, any>;
  local: Record<string, any>;
  paths: PlaceholderPaths;
}

/**
 * Merge *fragments* into one registry document: defaults, then fragments
 * (collisions fail), then the local overlay (which may override anything).
 */
export function mergeRegistry(fragments: Fragment[], opts: MergeOptions): Record<string, any> {
  const merged: Record<string, any> = {
    archetypes: structuredClone(opts.defaults["archetypes"] ?? {}),
    mcp_servers: structuredClone(opts.defaults["mcp_servers"] ?? {}),
    services: {},
    infrastructure: {},
    setup_services: {},
    repos: {},
  };
  const owners = new Map<string, string>();

  for (const fragment of fragments) {
    const doc = expandPlaceholders(fragment.doc, opts.paths);
    for (const key of Object.keys(doc)) {
      if (key.startsWith("x-") || (FRAGMENT_KEYS as readonly string[]).includes(key)) continue;
      throw new RegistryError(
        `${fragment.path}: unexpected top-level key \`${key}\` — a fragment may only ` +
          `contain ${FRAGMENT_KEYS.join(", ")} (and x-* anchor blocks)`,
      );
    }
    for (const section of FRAGMENT_KEYS) {
      const entries = doc[section] ?? {};
      if (!isDict(entries)) {
        throw new RegistryError(`${fragment.path}: \`${section}:\` must be a map`);
      }
      for (const [name, raw] of Object.entries(entries)) {
        if (!isDict(raw)) {
          throw new RegistryError(`${fragment.path}: \`${section}.${name}\` must be a map`);
        }
        claim(owners, `${section}/${name}`, fragment.repo, `${section}.${name}`);
        let entry: Record<string, any> = raw;
        if (section === "services" || section === "setup_services") {
          if (raw["repo"] !== undefined && raw["repo"] !== fragment.repo) {
            throw new RegistryError(
              `${fragment.path}: ${section}.${name} says repo: ${raw["repo"]} but lives in ${fragment.repo}`,
            );
          }
          entry = { repo: fragment.repo, ...raw };
        }
        if (section === "services") {
          if (entry["port_offset"] !== undefined) {
            claim(owners, `port_offset/${entry["port_offset"]}`, `${fragment.repo}:${name}`,
              `port_offset ${entry["port_offset"]}`);
          }
          const repoEntry = (merged["repos"][fragment.repo] ??= { services: [], path_mappings: {} });
          repoEntry.services.push(name);
          const svcPath = String(entry["path"] ?? ".").replace(/^\/+|\/+$/g, "");
          if (svcPath !== "" && svcPath !== ".") repoEntry.path_mappings[svcPath] = name;
        }
        if ((section === "services" || section === "infrastructure") && entry["k8s_forward_port"] !== undefined) {
          claim(owners, `k8s_forward_port/${entry["k8s_forward_port"]}`, `${fragment.repo}:${name}`,
            `k8s_forward_port ${entry["k8s_forward_port"]}`);
        }
        merged[section][name] = entry;
      }
    }
  }

  return deepMerge(merged, opts.local);
}

/** The generated file: marker header, then the document in OUTPUT_ORDER. */
export function renderRegistry(merged: Record<string, any>, sources: string[], localPath: string): string {
  const ordered: Record<string, any> = {};
  for (const key of OUTPUT_ORDER) if (key in merged) ordered[key] = merged[key];
  for (const key of Object.keys(merged)) if (!(key in ordered)) ordered[key] = merged[key];
  const header = [
    GENERATED_MARKER,
    "# Edit a repo's .sandbox/services.yaml fragment, or the machine overrides file, then",
    "# run `sandbox registry sync` (or `sandbox setup`). Regenerated from:",
    ...sources.map((s) => `# Source: ${s}`),
    `# Machine overrides: ${localPath}`,
    "",
  ].join("\n");
  return header + stringifyYaml(ordered, { lineWidth: 0 });
}
```

```ts
export interface SyncRegistryOptions {
  /** Defaults to `paths.repos_root`. */
  reposRoot?: string;
  /** Report what would happen; write nothing. */
  checkOnly?: boolean;
  /** Clock for the backup suffix (tests). */
  now?: () => number;
}

function placeholderPaths(): PlaceholderPaths {
  return { home: os.homedir(), repos_root: getReposRoot(), workspaces_root: workspacesRoot() };
}

function readLocalOverlay(localPath: string): Record<string, any> {
  if (!fs.existsSync(localPath)) return {};
  let doc: unknown;
  try {
    doc = parseYaml(fs.readFileSync(localPath, "utf8"));
  } catch (e) {
    throw new RegistryError(`${localPath}: ${e instanceof Error ? e.message : String(e)}`);
  }
  if (doc === null || doc === undefined) return {};
  if (!isDict(doc)) throw new RegistryError(`${localPath}: must be a map of registry keys`);
  return doc;
}

/**
 * Regenerate `~/.sandbox/services.yaml` from every fragment under repos_root.
 *
 * One Step, label `config services.yaml`, matching the other registry files'
 * steps in machine_setup. Never throws: a bad fragment or a collision is a
 * failing step whose detail is the RegistryError message.
 */
export function syncRegistry(opts: SyncRegistryOptions = {}): Step[] {
  const label = "config services.yaml";
  const reposRoot = opts.reposRoot ?? getReposRoot();
  const target = servicesYamlPath();
  const localPath = servicesLocalYamlPath();

  let fragments: Fragment[];
  let text: string;
  try {
    fragments = discoverFragments(reposRoot);
    if (fragments.length === 0) {
      return [{
        label,
        ok: false,
        detail:
          `no ${FRAGMENT_REL} found under ${reposRoot} — clone your team's repos there and ` +
          "re-run `sandbox setup` (or answer yes to the demo apps)",
      }];
    }
    const merged = mergeRegistry(fragments, {
      defaults: REGISTRY_DEFAULTS,
      local: readLocalOverlay(localPath),
      paths: placeholderPaths(),
    });
    text = renderRegistry(merged, fragments.map((f) => f.path), localPath);
  } catch (e) {
    return [{ label, ok: false, detail: e instanceof Error ? e.message : String(e) }];
  }

  const sources = `${fragments.length} fragment${fragments.length === 1 ? "" : "s"}`;
  const existing = fs.existsSync(target) ? fs.readFileSync(target, "utf8") : null;
  if (existing === text) {
    return [{ label, ok: true, detail: `up to date (${sources}) at ${target}` }];
  }
  if (opts.checkOnly) {
    return [{
      label,
      ok: false,
      detail: existing === null
        ? `missing — would generate ${target} from ${sources}`
        : `drift — would regenerate ${target} from ${sources}`,
    }];
  }

  let note = "";
  if (existing !== null && !existing.startsWith(GENERATED_MARKER)) {
    const stamp = Math.floor((opts.now ?? Date.now)() / 1000);
    const backup = `${target}.bak-${stamp}`;
    fs.copyFileSync(target, backup);
    note = `; hand-written registry backed up to ${backup}`;
  }
  try {
    fs.mkdirSync(path.dirname(target), { recursive: true });
    fs.writeFileSync(target, text);
  } catch (e) {
    return [{ label, ok: false, detail: `could not write ${target}: ${e}` }];
  }
  return [{ label, ok: true, detail: `generated ${target} from ${sources}${note}` }];
}
```

- [ ] **Step 2: Create the registry command**

Create `apps/cli/src/commands/registry.ts`:

```ts
/**
 * sandbox registry [sync] [--check]
 *
 * Regenerate ~/.sandbox/services.yaml from every <repo>/.sandbox/services.yaml
 * under paths.repos_root, merged under ~/.sandbox/services.local.yaml. The
 * same step `sandbox setup` runs, on its own: for the moment you clone a new
 * repo and want it registered without a full setup pass.
 *
 *   sandbox registry            # regenerate (sync is the default action)
 *   sandbox registry --check    # report drift; nonzero exit when stale
 */

import { Colors, success, warn } from "../lib/config.js";
import { syncRegistry } from "sandbox-core/registry_sync";

export async function run(args: Record<string, unknown>): Promise<void> {
  const action = String(args.action ?? "sync");
  if (action !== "sync") {
    warn(`Unknown action \`${action}\` — the only action is \`sync\` (the default).`);
    process.exit(2);
  }
  const check = Boolean(args.check);
  const steps = syncRegistry({ checkOnly: check });
  for (const step of steps) {
    const mark = step.ok ? `${Colors.GREEN}✓${Colors.RESET}` : `${Colors.RED}✗${Colors.RESET}`;
    console.log(`${mark} ${step.label}: ${step.detail}`);
  }
  if (steps.some((s) => !s.ok)) {
    warn(check ? "Registry is stale — run `sandbox registry sync`." : "Registry was not generated.");
    process.exit(1);
  }
  success(check ? "Registry is up to date." : "Registry generated.");
}
```
