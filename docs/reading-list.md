# Reading list

These books shaped how I think about building software well and shipping it often. Werkmeister borrows from each of them. This page keeps the citations in one place so the rest of the docs can point here.

The "What it changed" notes are mine. "Where it shows" is a first guess at the link to werkmeister. Fix it as the docs get written.

Buy links go to the publisher for now. If they become affiliate links, this page and every page that uses them must say so (see [Affiliate links](#affiliate-links)).
