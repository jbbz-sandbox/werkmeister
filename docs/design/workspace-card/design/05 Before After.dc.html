AFTER · CLAUDE CODE PANE
  1. 1
    Unlabelled counts. 0/2, 1/1 and up 2/2 say nothing about what's being counted.
    → containers 0 of 2 up, ICM stage 2 of 4. Every count names its unit.
  2. 2
    “waiting for you” on finished runs. It shows even when the PR is merged.
    → Four agent states. A finished run shows ✓ Done, and only a real question shows ● Needs you.
  3. 3
    Cut-off prompt as the session title. “…walk every stage without s”
    → The subtitle is Work type · task title. The prompt never appears on the card.
  4. 4
    No autonomous marker. The only sign of an autonomous run is “(auto)” buried in the prompt text.
    → ⚙ Auto on line 1 of the pane, ⚙ Autonomous on full cards.
  5. 5
    Unexplained green border. It means “containers up”, but people read it as “all good”.
    → Only ● Needs you changes the border. Container state is written in words, and a legend sits on every surface.
  6. 6
    Status text changes format between cards. “stage 1/4 reproduce · 0/2” on one card, “shipped — close out · 1/1” on another.
    → The same fixed line order on every card: containers · PRs · workflow.
  7. 7
    “PR open” next to “merged”. Two statements about one PR that contradict each other.
    → One state badge per PR: stellwerk#186 Released v0.14.0 · CI ✓
