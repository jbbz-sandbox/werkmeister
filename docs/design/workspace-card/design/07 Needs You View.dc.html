Needs-attention view

The count of waiting workspaces is in the tab label. One click filters the list to ● Needs you. Each waiting card can show the agent's last question and answer it with ↗ Continue in ….

Tab count

Workspaces · 2 need youNew workspace

The count is omitted when it's zero, so the label is just Workspaces. Singular is 1 needs you. PROPOSAL The browser tab title also gets a prefix: (2) Stellwerk.

Filter

A segmented control next to search: All · 5 / ● Needs you · 2. While the filter is on, its segment is solid amber, and that solid amber is used nowhere else. The filter can be combined with the search text.

Sort

PROPOSAL In the All view, Needs you cards always come first, oldest question first. The rest of the order is unchanged.

Question preview · collapsed → expanded

Collapsed: one line, cut off with an ellipsis. Expanded: the full question in 15px, the time, and the primary action. The text comes from the session's last AskUserQuestion or its final assistant message PROPOSAL. Answers happen where the session runs, never in the card.
