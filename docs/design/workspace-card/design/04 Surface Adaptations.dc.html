How the MCP App inherits the host

The card reads only --sd-* tokens. Inside the iframe the app maps each one to the host's variables, so the card has no colours or font of its own:

--sd-sans    → var(--font-sans)
--sd-card    → var(--color-background-primary)
--sd-bg      → var(--color-background-secondary)
--sd-ink     → var(--color-text-primary)
--sd-muted   → var(--color-text-secondary)
--sd-line    → var(--color-border-primary)
--sd-accent  → var(--color-text-primary)

Status colours (ok, warn, err, off, pr) are the only values the app ships, with a light and a dark set. It picks between them from the host's colour scheme.

PROPOSAL The primary button uses host ink rather than Stellwerk blue, so the app looks native in Claude. The dashboard keeps the blue.

Links open through the host's “open link”. ↗ Continue in Desktop asks the host. It never opens a window itself.
