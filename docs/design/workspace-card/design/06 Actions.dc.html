Notes

The VS Code menu holds every command, because tree nodes have no action bar. The groups are: continue / switch · lifecycle · session · overflow · destructive.

Open issue ↗ is disabled, not hidden, when there's no issue, so items never change position.

✕ Abandon… always comes last, after a divider, in the err colour.
