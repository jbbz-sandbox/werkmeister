The Workspaces view is now wrapping cards in a webview, not a tree, so nothing is cut off when the side bar is narrow. Each card shows the agent's activity and the model, the stage with its name (`stage 2/4 implement`), a link to the issue and to each PR, every container with its state, and an **Open terminal** button that focuses the workspace's session terminal or continues the session in a new one, and one button for the run beside it: **▶ Start work** opens a session with the starting prompt on a workspace nobody has started, **⏸ Pause** holds a live run and freezes its containers, **▶ Resume** picks it back up. **Master control** at the top focuses the chat at the workspaces root, or starts one there, and **Dashboard ↗** beside it opens the workspaces dashboard in the browser. The row's hover icons are gone: the container commands (Up, Stop, Restart, Down), Open in New Window, Open feature, Logs, Close out and Abandon are on the card's right-click menu, and Toggle Intercept on a service's.
